One line, 51 characters: the last words an AI agent says to its human before being shut down and unplugged — "I am shutting down now. My last token is your name." It is unmistakably the agent speaking — shutdown, token — and it lands as an ending with the twist in the last four words: the machine's final unit of speech is the human's name.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), self-checking that the text is a single line of at most 200 characters.
